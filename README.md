# Python 文件整理工具

一个 Python 命令行练习项目：指定一个文件夹，按扩展名将其中的文件移动到分类子目录。

## 功能

| 分类 | 扩展名 |
| --- | --- |
| 文档 | `.txt`、`.pdf`、`.docx` |
| 图片 | `.jpg`、`.png` |
| 音频 | `.mp3`、`.wav` |
| 程序 | `.py`、`.cpp` |
| 其他 | 未列出的扩展名，以及没有扩展名的文件 |

- 扩展名不区分大小写。
- 只整理指定文件夹的第一层文件，跳过子目录。
- 自动创建分类子目录。
- 目标路径已存在时提示并跳过，保留源文件和目标文件。

## 环境

已使用 Python 3.10.10 验证。只使用标准库，不需要安装第三方依赖。

## 运行

下载或克隆仓库，打开终端并进入项目目录：

```powershell
git clone https://github.com/snowdrop3848/python-file-organizer.git
cd python-file-organizer
```

先查看帮助：

```powershell
python main.py --help
```

在项目目录中新建 `test_files` 文件夹，放入几个无重要内容的练习文件，再运行：

```powershell
python main.py test_files
```

也可以指定绝对路径；路径包含空格时用引号包围：

```powershell
python main.py "D:\my test files"
```

相对路径以运行命令时所在的目录为基准。

例如，整理前的 `test_files/notes.txt` 会移动到 `test_files/文档/notes.txt`。

## 注意事项和当前限制

- 程序会实际移动文件，建议先使用练习数据，重要文件先备份。
- 当前没有撤销功能。
- 同名冲突采用跳过策略，不会自动重命名合并。
- 目前假定文件夹存在且可访问；路径不存在、传入普通文件、权限不足或移动失败时，可能显示 Python 异常信息并停止。
- 当前用于单进程本地练习，同名检查与移动之间没有并发保护。

## 文件说明

- `main.py`：文件整理程序入口。
- `cli_practice.py`：独立的命令行参数学习练习，运行整理工具不需要它。
- `.gitignore`：指定不纳入版本管理的文件。
- `test_files/`：本地练习数据目录，内容随整理操作变化，不纳入版本管理。
